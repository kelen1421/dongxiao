## 开屏顺序

黑底停留 → 左上终端文字逐行出现 → 浅色矩形向上下展开并伴随故障条带 → 黄绿色光晕与背景细节显现 → 中央 Logo 轮廓形成并补出“+ / −” → 短暂停留。

## Logo 向左上移动

约 2.70—2.73 秒开始，向左、向上移动，同时等比例缩小；左侧字标开始出现。可见部分起步较慢，随后加速，没有明显旋转或回弹。
