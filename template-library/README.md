# KELEN · 结构收藏库

[打开网页](https://kelen1421.github.io/dongxiao/template-library/)

收录 Kelen 在 2026-10-29 筛选保留的 **106 个结构**。原目录 119 个，去除 13 个，编号清单见 `selection.json`。

- 分类、名称与编号搜索；放大体验和重播。
- 星标、去除、恢复、撤销和 JSON 清单导出。
- 筛选仅更新相关卡片，保留其他预览实例；画面外预览按需释放。
- 选择保存在当前浏览器，与原始筛选页分开保存；其他设备可用导出文件留存清单。
- 页面中的数字与文案是模板演示数据，不是个人履历。
